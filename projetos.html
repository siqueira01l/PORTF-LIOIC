Projeto em Equipe

FitPlanner

Aplicação desenvolvida para auxiliar na organização e acompanhamento de rotinas fitness, reunindo ferramentas de planejamento de treinos e monitoramento de progresso em uma experiência prática e intuitiva.

Ver no GitHub

Participação

No projeto FitPlanner, fui responsável pelo desenvolvimento de todo o front-end da aplicação e pela integração das interfaces com o back-end. Também contribuí na correção de alguns bugs do servidor e participei do desenvolvimento da funcionalidade Extras, implementando cálculos como IMC, RCQ, IMG e BF. Essa experiência me permitiu atuar em diferentes etapas do projeto, desde a construção da interface até a resolução de problemas e implementação de novas funcionalidades.

Objetivo

Facilitar o planejamento e acompanhamento de treinos, oferecendo uma interface clara para quem busca mais consistência nos objetivos fitness.

HTML CSS JavaScript Python Flask SQLite SQLalchemy

Funcionalidades

O FitPlanner possui funcionalidades como gerenciamento de treinos e planos de exercícios, armazenamento de informações em banco de dados e uma interface intuitiva para facilitar o acompanhamento das atividades. O sistema permite organizar e acessar dados de forma prática, proporcionando uma melhor experiência ao usuário.

Aprendizados

No projeto FitPlanner, aprendi a desenvolver uma aplicação web utilizando Flask, Python, HTML, CSS e JavaScript, além de gerenciar dados com SQL e SQLAlchemy. O projeto me ajudou a entender a integração entre front-end, back-end e banco de dados, aprimorando minhas habilidades em desenvolvimento web.
