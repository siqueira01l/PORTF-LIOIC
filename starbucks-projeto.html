Projeto Individual

Starbucks Landing Page

Landing page desenvolvida para recriar a identidade visual da Starbucks, com foco em design responsivo, animações suaves e uma experiência de navegação agradável e fiel à marca.

Ver no GitHub

Participação

Projeto desenvolvido de forma individual, sendo responsável por todas as etapas — desde o planejamento do layout até a implementação final. Trabalhei na construção da estrutura HTML semântica, na estilização completa com CSS puro incluindo animações e responsividade, e na adição de interatividade com JavaScript. O projeto foi um exercício de fidelidade visual a uma marca consolidada, exigindo atenção a detalhes como paleta de cores, tipografia e fluidez na navegação.

Objetivo

Recriar a experiência visual da Starbucks em uma landing page moderna e responsiva, praticando habilidades de UI com HTML, CSS e JavaScript sem o uso de frameworks.

Tecnologias

HTML CSS JavaScript

Funcionalidades

A landing page conta com seções de destaque de produtos, navegação com menu responsivo, animações de scroll, carrossel de itens do cardápio e um layout adaptado para dispositivos móveis, tablets e desktops.

Aprendizados

O projeto aprofundou meu entendimento de CSS avançado — incluindo variáveis, flexbox, grid e animações — além de consolidar práticas de JavaScript para manipulação do DOM. Também aprendi a traduzir uma identidade de marca real para código de forma consistente.
